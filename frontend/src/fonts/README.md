# JetBrainsMono Nerd Font web assets

`JetBrainsMonoNerdFont-Regular.woff2` and
`JetBrainsMonoNerdFont-Bold.woff2` are WOFF2-compressed copies of the matching
TTF files in the official Nerd Fonts 3.5.0 `JetBrainsMono.tar.xz` release
archive.

The archive SHA-256 and resulting WOFF2 SHA-256 values are pinned in
`reproducible.env`. The font is distributed under the SIL Open Font License
1.1; its license text is in `LICENSES/JetBrainsMonoNerdFont-OFL-1.1.txt`.
